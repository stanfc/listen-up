⚡ 最快 30 秒啟動遊戲！

1️⃣  打開終端，進入 backend 資料夾
   cd backend
   npm run dev

2️⃣  打開另一個終端，進入 frontend 資料夾
   cd frontend
   npm run dev

3️⃣  打開瀏覽器，訪問
   http://localhost:5173

4️⃣  邀請朋友圍坐在一起
   開始玩！ 🎉


📋 簡單說明
────────────────────────────────────────────────────────────────

遊戲目標:
  首位達到 5 張卡牌（按年份順序排列）的玩家獲勝！

自動預設:
  4 個玩家（玩家1、玩家2、玩家3、玩家4）
  打開即玩，無需任何配置！

遊戲流程:
  1. 當前玩家聽歌 🎵
  2. 猜歌曲名稱 🎤
  3. 猜發行年份 📅
  4. 在時間線上放置卡牌 🃏
  5. 輪到下一個玩家


🎛️  快速自定義
────────────────────────────────────────────────────────────────

要改玩家名字？
  編輯: frontend/src/components/QuickGame.vue
  找到: const presetPlayers = ['玩家1', '玩家2', '玩家3', '玩家4']
  改成: const presetPlayers = ['Alice', 'Bob', 'Charlie', 'David']

要改玩家人數？
  只需添加或刪除上面的名字即可
  比如 3 個玩家: ['玩家1', '玩家2', '玩家3']

要改音樂選擇？
  編輯: frontend/src/components/QuickGame.vue
  找到: musicTags: ['80s', '2000s', '2010s', 'pop', 'rock'],
  改成: musicTags: ['pop']  (只要 pop 音樂)

🐛 常見問題
────────────────────────────────────────────────────────────────

Q: 後端出錯 "Address already in use"
A: 3000 端口被占用，改用其他端口或重啟電腦

Q: 前端無法連接後端
A: 確保後端在 localhost:3000 運行，刷新頁面

Q: 看不到音樂播放
A: 檢查瀏覽器音量和系統音量

Q: 想添加自己的歌曲
A: 編輯 backend/data/music.json，添加新歌曲
